# lines-counter-Arabic-and-English

أداة عربية وإنجليزية تعرض إجمالي أسطر المشروع وعدد ملفاته وتوزيع الأسطر والملفات حسب اللغة. افتح `index.html` في متصفح يدعم اختيار المجلدات واختر مجلد مشروعك.

A bilingual Arabic and English project statistics tool. Open `index.html` in a browser with folder picker support, then choose your project folder.

- Counts nonblank lines including comments. Common dependency and build folders are skipped.
- Analyzes files locally and stores the report history and appearance preferences in your browser.
- Supports light and dark themes, a custom accent color, and bulk deletion of selected reports.
